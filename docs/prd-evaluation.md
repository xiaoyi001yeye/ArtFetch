## 1. 背景

当前 ArtFetch 已支持从 Artron 抓取艺术品拍卖数据，并提供艺术品列表、筛选、详情查看和 Excel 导出能力。

新增“评估”功能后，用户可以基于已有艺术品数据创建评估项目，按照可配置条件选定一批艺术品，再由专家根据预设或自定义的评估指标进行打分，最终形成专家估价结果。

该功能的核心目标是把“艺术品数据管理”扩展为“艺术品价值评估管理”，让评估过程可配置、可复用、可追踪。

## 2. 目标

### 2.1 业务目标

- 支持管理员创建一次艺术品评估项目。
- 支持通过可配置条件选择需要评估的艺术品。
- 支持预先维护评估指标定义，形成可复用的指标库。
- 支持预先维护评估指标模板，创建评估项目时可直接导入模板。
- 支持管理员从指标库中拖拽指标定义到评估项目。
- 支持系统根据评估项目中的艺术品、专家和指标，自动生成每个“专家 + 艺术品”组合的专家评估页面。
- 支持每个评估条件配置可使用的字段，例如作者、拍卖公司、拍卖日期、估价、材质等。
- 支持一个评估项目分配多个专家。
- 支持管理员创建、编辑、删除评估项目。
- 支持每个专家独立对每件艺术品按多个指标打分。
- 支持专家使用系统登录账号访问“我的评估”，不允许匿名或仅凭专家名称进入。
- 支持专家之间互不可见，专家不能看到其他专家的评分、评语和估价。
- 支持管理员查看评估结果与进度，但不能代替专家填写、提交或修改专家评估内容。
- 支持专家给出最终估价。
- 支持评估项目在专家完成评估后进入审核阶段。
- 支持审核人对评估结果进行通过或驳回。
- 支持审核人按“某专家对某艺术品的单条评估”进行单独驳回。
- 支持审核人仅查看已进入审核流的专家评估结果，不能看到专家草稿。
- 支持查看评估结果和评估进度。

### 2.2 产品目标

- 让评估流程结构化、可复用、可追踪。
- 评估指标可以动态定义，不固定写死。
- 常用评估指标可以沉淀为模板，减少重复配置。
- 管理员能通过拖拽方式快速组装评估项目。
- 一次评估项目可以覆盖多件艺术品。
- 创建评估项目时，艺术品筛选条件可以根据业务场景灵活配置。
- 评估项目进入执行后，项目范围保持稳定，避免艺术品、专家、指标被中途调整造成评估口径不一致。

## 3. 用户角色

### 3.1 管理员

负责创建评估项目、选择艺术品、配置评估条件、维护指标定义、导入指标模板、拖拽指标到项目、指定专家、查看结果。

主要操作：

- 创建评估项目。
- 编辑评估项目。
- 删除评估项目。
- 设置评估项目名称、说明。
- 配置艺术品筛选条件。
- 选择需要纳入评估的艺术品。
- 维护评估指标定义。
- 选择评估指标模板，或从指标库拖拽指标定义到评估项目。
- 调整本次评估项目中的指标顺序、必填规则和分值范围。
- 指定一个或多个专家。
- 查看评估进度。
- 查看评估结果。
- 不能代替专家填写、保存、提交或修改专家评估内容。

### 3.2 专家

负责对被分配的艺术品进行评估。专家必须使用系统登录账号访问，并以账号身份与评估记录绑定。

主要操作：

- 查看待评估艺术品。
- 查看艺术品详情。
- 按指标打分。
- 填写指标评语或整体评语。
- 填写最终估价。
- 保存草稿。
- 提交评估结果。

### 3.3 审核人

负责审核专家提交后的评估项目，确认评估数据是否完整、评分是否合理、最终估价是否可发布。

主要操作：

- 查看待审核评估项目。
- 查看评估项目整体信息。
- 查看每件艺术品下各专家已提交的评分、评语和最终估价。
- 填写审核意见。
- 审核通过评估项目。
- 驳回某个专家对某件艺术品的单条评估，并要求该专家修改。
- 不能查看专家草稿态评估内容。

## 5. 核心概念

### 5.1 评估项目 Evaluation Project

评估项目代表一次完整的评估工作。

示例：

> 2026 春拍中国当代绘画市场价值评估

一个评估项目包含：

- 项目名称。
- 项目说明。
- 艺术品筛选条件。
- 被评估艺术品列表。
- 本次项目使用的评估指标。
- 专家列表。
- 审核人。
- 状态。
- 创建时间。
- 完成时间。

项目配置边界建议：

- 管理员可创建、编辑、删除评估项目。
- 在 `DRAFT`、`PENDING` 状态下，管理员可调整艺术品范围、专家列表和项目评估指标。
- 评估项目一旦进入 `IN_PROGRESS` 及其后续状态，不允许再修改艺术品列表、专家列表和项目评估指标。
- 评估项目进入执行后，如确需调整范围，建议通过取消原项目并新建项目的方式处理，避免评估口径混乱。

### 5.2 评估指标定义 Evaluation Metric Definition

评估指标定义是系统中的可复用指标。管理员先在指标库中定义指标，然后在创建或编辑评估项目时，将指标拖拽到项目中使用。

评估指标定义不直接等同于某次评估项目里的指标。它是可复用的原始定义；被拖入评估项目后，系统应复制为本次项目的指标快照。

示例：

| 指标名称 | 说明 | 默认分值范围 |
|---|---|---|
| 色彩 | 色彩表现力、协调性、艺术感染力 | 1-10 |
| 笔触 | 笔触成熟度、风格辨识度 | 1-10 |
| 构图 | 画面结构、空间关系、视觉平衡 | 1-10 |
| 保存状况 | 品相、修复痕迹、保存完整度 | 1-10 |
| 市场热度 | 当前市场关注度和流通表现 | 1-10 |
| 艺术家影响力 | 艺术家学术地位、市场认可度 | 1-10 |

### 5.3 评估指标定义对象字段

评估指标定义建议包含以下字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 指标定义 ID |
| code | String | 指标编码，用于系统内部稳定识别，例如 `color_expression` |
| name | String | 指标名称，例如“色彩” |
| description | Text | 指标说明 |
| category | String | 指标分类，例如“艺术表现”“市场价值”“保存状况” |
| applicableArtworkTypes | JSON / String | 适用艺术品类型，例如书画、油画、瓷器、雕塑 |
| scoreType | Enum | 评分类型，例如数值评分、等级评分、选项评分、文本评价 |
| minScore | Decimal | 最小分值，数值评分时使用 |
| maxScore | Decimal | 最大分值，数值评分时使用 |
| scoreStep | Decimal | 分值步长，例如 1 或 0.5 |
| defaultWeight | Decimal | 默认权重，第一版可先保存但不参与计算 |
| required | Boolean | 默认是否必填 |
| inputComponent | String | 专家评估页面中的默认输入控件，例如 slider、rate、select、textarea |
| scoringGuide | Text | 评分说明，帮助专家理解如何打分 |
| scoringRubric | JSON | 分档评分标准，例如 1-3、4-7、8-10 分分别代表什么 |
| unit | String | 指标单位，可选，例如分、级 |
| tags | JSON / String | 标签，便于检索 |
| enabled | Boolean | 是否启用 |
| sortOrder | Integer | 默认排序 |
| version | Integer | 指标定义版本 |
| createdBy | String | 创建人 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

字段规则：

- `code` 应保持稳定，不建议随意修改。
- `name`、`description`、`scoringGuide` 可编辑。
- 修改指标定义后，应增加指标定义版本。
- 历史评估项目应使用拖入项目时的指标快照，不受后续指标定义变更影响。
- 停用指标定义后，不影响已创建评估项目。

### 5.4 评估指标模板 Evaluation Metric Template

评估指标模板是一组预先配置好的指标集合。创建评估项目时，用户可以直接导入模板，快速生成本次评估所需的指标。

示例模板：

| 模板名称 | 适用场景 | 指标示例 |
|---|---|---|
| 中国书画评估模板 | 书法、国画、水墨作品 | 笔墨、构图、题跋、保存状况、艺术家影响力 |
| 油画评估模板 | 油画、综合材料绘画 | 色彩、笔触、构图、题材、保存状况 |
| 市场价值评估模板 | 以交易价值判断为主 | 稀缺性、市场热度、历史成交、流通性、艺术家影响力 |

模板要求：

- 模板可新增、编辑、停用。
- 模板内可包含多个评估指标定义。
- 模板内指标可设置默认分值范围。
- 模板内指标可设置是否必填。
- 模板内指标可设置排序。
- 创建评估项目时导入模板后，应复制一份指标快照到本次评估项目。
- 后续修改模板，不应影响已创建评估项目中的历史指标。

### 5.5 项目评估指标 Evaluation Project Metric

项目评估指标是某个评估项目实际使用的指标。它可以来自指标定义拖拽，也可以来自指标模板导入，也可以在项目中临时新增。

项目评估指标需要保存快照，避免指标定义或模板变更影响历史项目。

字段建议：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 项目指标 ID |
| evaluationId | Long | 所属评估项目 ID |
| sourceMetricDefinitionId | Long | 来源指标定义 ID，可为空 |
| sourceTemplateId | Long | 来源模板 ID，可为空 |
| sourceVersion | Integer | 来源指标定义版本 |
| code | String | 指标编码快照 |
| name | String | 指标名称快照 |
| description | Text | 指标说明快照 |
| category | String | 指标分类快照 |
| scoreType | Enum | 评分类型 |
| minScore | Decimal | 最小分值 |
| maxScore | Decimal | 最大分值 |
| scoreStep | Decimal | 分值步长 |
| weight | Decimal | 本项目中的指标权重 |
| required | Boolean | 本项目中是否必填 |
| inputComponent | String | 本项目专家评估页面中的输入控件 |
| scoringGuide | Text | 评分说明快照 |
| scoringRubric | JSON | 分档评分标准快照 |
| sortOrder | Integer | 本项目中的排序 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

### 5.6 评估条件 Evaluation Criteria

评估条件用于从已有艺术品数据中筛选出需要评估的艺术品。

评估条件不是固定字段，而是可以由用户选择哪些艺术品字段参与筛选。

可选字段建议包括：

| 字段 | 含义 | 条件类型示例 |
|---|---|---|
| title | 拍品名称 | 包含、不包含、等于 |
| lotNumber | 拍品编号 | 等于、包含 |
| artist | 作者 | 等于、包含 |
| medium | 材质 | 等于、包含 |
| format | 形制 | 等于、包含 |
| dimensions | 尺寸 | 包含 |
| valuation | 拍卖估价 | 包含、金额区间 |
| auctionHouse | 拍卖公司 | 等于、包含 |
| auctionName | 拍卖会 | 等于、包含 |
| auctionSession | 拍卖专场 | 等于、包含 |
| auctionDate | 拍卖日期 | 等于、年份、日期区间 |
| auctionLocation | 拍卖地点 | 等于、包含 |
| previewTime | 预展时间 | 包含、日期区间 |
| previewLocation | 预展地点 | 等于、包含 |
| taskId | 抓取任务 | 等于 |
| externalId | 外部 ID | 等于 |

条件配置要求：

- 创建评估项目时，用户可以选择多个筛选字段。
- 每个字段根据字段类型展示不同的操作符。
- 文本字段支持包含、等于、不为空。
- 日期字段支持年份、具体日期、日期区间。
- 金额字段可先支持文本包含，后续如果估价结构化后支持金额区间。
- 多个条件默认使用 AND 关系。
- 后续可扩展 OR 条件组。
- 创建评估项目时应展示匹配艺术品数量和列表预览。
- 用户最终确认后，系统应保存当时选中的固定艺术品列表，避免后续数据变化影响评估范围。

### 5.7 专家评估 Expert Review

专家评估是某个专家针对某件艺术品提交的一组结果。在多专家模式下，同一个评估项目中的同一件艺术品会对应多条专家评估记录，每条记录归属于一个专家。

包含：

- 艺术品。
- 专家。
- 各指标评分。
- 指标评语。
- 整体评语。
- 最终估价。
- 评估状态。
- 提交时间。

关键约束：

- 专家评估记录的唯一性建议为 `evaluationId + artworkId + expertId`。
- 专家必须使用系统登录账号访问自己的评估记录，评估记录与 `expertId` 强绑定，不使用仅靠姓名的匿名模式。
- 专家只能查看和编辑自己的评估记录。
- 管理员不能代替专家创建、填写、保存、提交或修改专家评估记录。
- 专家提交前、提交后默认都不能查看其他专家的评分、评语和最终估价。
- 管理员可在评估详情查看多专家汇总结果。
- 审核人只能查看已进入审核流的专家评估结果，不能查看草稿态专家评估内容。
- 多专家评估完成进度应按“艺术品数量 × 专家数量”计算，而不是只按艺术品数量计算。

### 5.8 评估项目专家 Evaluation Project Expert

评估项目专家表示某个评估项目分配了哪些专家。

字段建议：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 项目专家 ID |
| evaluationId | Long | 评估项目 ID |
| expertId | Long | 专家账号 ID |
| expertName | String | 专家展示名称快照 |
| status | Enum | 专家在本项目中的状态 |
| assignedAt | DateTime | 分配时间 |
| completedCount | Integer | 该专家已完成评估数量 |
| totalCount | Integer | 该专家应完成评估数量 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

约束建议：

- 专家分配必须基于系统内已存在的专家账号。
- 项目中展示的 `expertName` 为分配时的名称快照，权限判断必须以 `expertId` 为准。

### 5.9 评估审核 Evaluation Audit

评估审核是评估项目在专家完成评估后进入的质量控制阶段。审核人需要检查评估项目中的艺术品评估结果是否完整、评分是否符合指标要求、最终估价是否合理，并给出审核结论。

审核结论包括：

| 结论 | 说明 |
|---|---|
| APPROVED | 审核通过，评估项目结果可进入已完成或可发布状态 |
| REJECTED | 审核驳回，指定某专家对某艺术品的单条评估需要返回修改 |

审核内容建议包括：

- 是否所有艺术品均已被所有指定专家完成评估。
- 是否所有必填指标均已评分。
- 是否存在明显异常评分。
- 是否存在缺失评语或说明不足。
- 最终估价是否填写完整。
- 最终估价币种是否明确。
- 是否需要某个专家重新评估某件艺术品。

审核要求：

- 评估项目只有在所有指定专家完成全部艺术品评估后，才能提交审核。
- 审核人仅能查看 `SUBMITTED`、`RESUBMITTED` 或已进入审核流的专家评估内容，不能查看 `DRAFT` 或 `NOT_STARTED` 数据明细。
- 审核通过后，评估项目进入完成状态。
- 审核驳回后，被驳回的单条专家评估返回可修改状态，并记录驳回原因。
- 每次审核操作都应保留审核记录。
- 审核记录不应被覆盖，便于追踪历史。

## 6. 用户流程

### 6.1 评估指标定义管理流程

1. 管理员进入“评估指标库”页面。
2. 点击“新建指标”。
3. 填写指标名称、编码、分类、说明、适用艺术品类型。
4. 设置评分类型、分值范围、分值步长、默认权重、是否必填。
5. 配置专家评估页面的输入控件。
6. 填写评分说明和分档评分标准。
7. 保存后，指标进入指标库。
8. 管理员可在创建评估项目时搜索、筛选、拖拽该指标。

### 6.2 创建评估项目流程

1. 管理员进入“评估管理”页面。
2. 点击“新建评估项目”。
3. 填写项目名称和项目说明。
4. 配置艺术品筛选条件。
5. 选择参与筛选的艺术品字段。
6. 为每个字段设置操作符和值。
7. 系统根据条件展示匹配艺术品数量和列表预览。
8. 管理员确认纳入评估项目的艺术品。
9. 管理员选择评估指标模板并导入，或从评估指标库拖拽指标定义到项目中。
10. 管理员可在导入或拖拽后继续新增、删除、排序或调整本次项目指标。
11. 管理员指定一个或多个专家账号。
12. 提交创建。
13. 系统生成评估项目，状态为“待评估”。
14. 系统根据评估项目中的艺术品列表、专家列表和项目指标，为每个“专家 + 艺术品”组合生成独立专家评估记录和评估页面。

### 6.3 编辑 / 删除评估项目流程

1. 管理员在评估管理页或详情页点击“编辑”或“删除”。
2. 当项目状态为 `DRAFT` 或 `PENDING` 时，管理员可编辑项目名称、说明、艺术品范围、项目指标和专家列表。
3. 当项目状态进入 `IN_PROGRESS` 及之后状态时，系统锁定艺术品列表、专家列表和项目指标，不允许再修改。
4. 进入锁定状态后，如仍允许编辑，则仅可修改不影响评估口径的基础信息，例如项目说明。
5. 管理员删除项目时，系统应二次确认，并提示删除影响。
6. 已进入执行或已产生审核记录的项目，建议不做物理删除，改为逻辑删除或仅允许取消，以保留过程痕迹。

### 6.4 指标拖拽到评估项目流程

1. 管理员打开评估项目编辑页。
2. 页面左侧展示“评估指标库”，支持按分类、名称、标签、适用艺术品类型检索。
3. 页面右侧展示“本项目评估指标”。
4. 管理员将指标定义从左侧拖拽到右侧。
5. 系统将指标定义复制为本项目指标快照。
6. 管理员可调整本项目指标的排序、必填状态、分值范围、权重、输入控件和评分说明。
7. 保存项目后，系统按项目指标生成或更新专家评估表单。

### 6.5 评估指标模板使用流程

1. 管理员进入“评估指标模板”页面。
2. 新建或维护模板。
3. 在模板中添加多个指标定义。
4. 设置模板内指标说明、分值范围、是否必填、排序。
5. 创建评估项目时选择某个模板。
6. 系统将模板中的指标复制到本次评估项目。
7. 管理员可对本次评估项目的指标做局部调整。
8. 模板后续修改不影响已创建评估项目。

### 6.6 专家评估流程

1. 专家登录系统后进入“我的评估”页面。
2. 查看待评估艺术品列表。
3. 点击某件艺术品进入系统自动生成的专家评估页面。
4. 查看艺术品详情，包括标题、作者、材质、尺寸、拍卖公司、估价、图片、来源链接等。
5. 查看本项目配置的评估指标、评分说明和分档标准。
6. 对每个指标打分。
7. 填写指标评语或整体评语。
8. 填写最终估价。
9. 保存草稿或提交。
10. 系统保存评估结果。
11. 专家只能查看自己的评分、评语和估价，不能查看其他专家对同一艺术品的评估内容。
12. 管理员不能进入该专家的编辑态页面，也不能代替专家填写或修改该条评估。
13. 若该评估项目下所有专家均完成所有艺术品评估，评估项目状态可变为“待提交审核”。

### 6.7 评估项目审核流程

1. 所有指定专家完成评估项目下全部艺术品的评估。
2. 系统将评估项目状态更新为“待提交审核”。
3. 管理员或专家点击“提交审核”。
4. 系统校验所有“专家 + 艺术品”评估是否完整、必填指标是否完成、最终估价是否填写。
5. 校验通过后，评估项目状态更新为“审核中”。
6. 审核人进入“待审核评估项目”页面。
7. 审核人查看评估项目基本信息、筛选条件、指标配置、按艺术品和专家组织的已提交评估结果。
8. 审核人填写审核意见。
9. 审核人可以选择“审核通过项目”，也可以针对某个“专家 + 艺术品”的单条评估选择“驳回修改”。
10. 审核通过项目后，评估项目状态更新为“已完成”。
11. 单条评估被驳回后，该专家评估记录状态更新为“审核驳回”，评估项目状态更新为“审核驳回”。
12. 系统保存驳回原因，并通知对应专家修改该件艺术品的评估。
13. 被驳回的专家修改并重新提交后，项目可再次提交审核。
14. 审核页不展示任何处于 `DRAFT` 或 `NOT_STARTED` 的专家评估明细。

### 6.8 查看结果流程

1. 管理员进入评估项目详情页。
2. 查看整体进度，包括总艺术品数、专家数、应完成评估数、已提交评估数、未提交评估数、完成率。
3. 查看艺术品评估列表。
4. 点击单件艺术品查看各专家的详细评分。
5. 查看每位专家的最终估价和专家评语。
6. 查看审核状态、审核意见和审核历史。

7. 专家多选。

### 7.3 评估条件配置区

该区域用于选择“用哪些字段筛选艺术品”。

建议交互：

- 每行条件包含字段、操作符、值。

### 7.8 专家评估页

路径建议：

`/evaluations/:evaluationId/artworks/:artworkId/review`

页面由系统根据项目指标自动生成。

展示内容：

- 艺术品详情。
- 本项目评估指标表单。
- 各指标评分输入。
- 指标评分说明。
- 指标评语。
- 整体评语。
- 最终估价。
- 保存草稿。
- 提交评估。

自动生成规则：

- 系统读取评估项目中的项目指标列表。
- 系统根据当前登录专家账号，只加载该专家自己的评估记录。
- 按 `sortOrder` 生成表单顺序。
- 根据 `inputComponent` 选择评分控件。
- 根据 `scoreType`、`minScore`、`maxScore`、`scoreStep` 设置输入约束。
- 必填指标未填写时不允许提交。
- 评分说明和分档标准应展示给专家参考。
- 页面不展示其他专家对同一艺术品的评分、评语和估价。
- 非该专家本人登录时，不允许进入编辑态。

### 7.9 评估审核页

路径建议：

`/evaluations/:id/audit`

展示内容：

- 评估项目基本信息。
- 艺术品总数、专家数量、应完成评估数、已提交评估数、未提交评估数。
- 本项目评估指标列表。
- 每件艺术品下各专家已提交的评分、评语、最终估价。
- 异常提示，例如缺失评分、缺失估价、评分超出范围。
- 历史审核记录。
- 审核意见输入框。
- 审核通过按钮。
- 单条专家评估驳回按钮。

审核页规则：

- 只有状态为 `IN_REVIEW` 的评估项目允许审核通过或驳回。
- 如果系统检测到必填项缺失，应提示审核人并阻止审核通过。
- 审核页不展示草稿态专家评估内容。
- 审核驳回时必须选择具体专家和具体艺术品，并填写驳回原因。
- 驳回只影响被选中的单条专家评估记录。
- 审核通过后，评估项目进入 `COMPLETED` 状态。

## 8. 状态设计

### 8.1 评估项目状态

| 状态 | 说明 |
|---|---|
| DRAFT | 草稿 |
| PENDING | 待评估 |
| IN_PROGRESS | 评估中，项目范围已锁定，不允许再修改艺术品、专家、项目指标 |
| READY_FOR_REVIEW | 待提交审核，所有“专家 + 艺术品”评估均已完成但尚未提交审核 |
| IN_REVIEW | 审核中 |
| REVIEW_REJECTED | 审核驳回，存在至少一条专家评估需修改后重新提交审核 |
| COMPLETED | 已完成 |
| CANCELLED | 已取消 |

建议状态流转：

```text
DRAFT -> PENDING -> IN_PROGRESS -> READY_FOR_REVIEW -> IN_REVIEW -> COMPLETED
                                      ^                 |
                                      |                 v
                                      +--------- REVIEW_REJECTED
```

### 8.2 单件艺术品评估状态

| 状态 | 说明 |
|---|---|
| NOT_STARTED | 未开始 |
| DRAFT | 草稿 |
| SUBMITTED | 已提交 |

### 8.3 单条专家评估状态

| 状态 | 说明 |
|---|---|
| NOT_STARTED | 未开始 |
| DRAFT | 草稿 |
| SUBMITTED | 已提交 |
| REVIEW_REJECTED | 审核驳回，需对应专家修改 |
| RESUBMITTED | 驳回后已重新提交 |

### 8.4 指标定义状态

| 状态 | 说明 |
|---|---|
| ENABLED | 启用 |
| DISABLED | 停用 |

### 8.5 审核结论

| 结论 | 说明 |
|---|---|
| APPROVED | 审核通过 |
| REJECTED | 审核驳回 |

- 每次提交审核、审核通过、单条专家评估驳回都建议保留记录。
- `expertReviewId` 为空时，表示项目级审核记录；不为空时，表示针对某条专家评估的审核记录。
- `action` 用于区分提交审核、项目审核通过、单条评估驳回等动作。
- 审核记录用于项目追踪，不应被覆盖或删除。

## 10. 关键规则

1. 一次评估项目必须至少包含一件艺术品。
2. 一次评估项目必须至少包含一个评估指标。
3. 评估指标可以从指标库拖拽加入，也可以从模板导入，也可以在项目内临时新增。
4. 从指标库拖拽或从模板导入后，本次评估项目应保存指标快照。
5. 后续修改指标定义或模板，不影响历史评估项目。
6. 每个数值指标的分值范围默认建议为 1-10。
7. 专家提交评估前，必须完成所有必填指标评分。
8. 最终估价为必填项。
9. 已提交的评估结果默认不可随意修改，后续可增加“重新打开评估”能力。
10. 评估条件应保存创建时的条件快照。
11. 评估关联艺术品应保存创建时确认的固定列表，避免后续新增数据自动进入已创建评估。
12. 评估条件默认使用 AND 关系。
13. 停用指标定义或模板不影响历史评估项目。
14. 管理员可创建、编辑、删除评估项目，但删除应遵循审计保留策略，优先逻辑删除或取消项目。
15. 评估项目进入 `IN_PROGRESS` 后，不允许修改艺术品列表、专家列表和项目指标。
16. 评估项目创建或项目指标变更后，系统应能为每个“专家 + 艺术品”组合生成或更新专家评估页面。
17. 专家评估页面生成应以项目指标快照为准。
18. 多专家评估下，系统应为每个“专家 + 艺术品”组合生成一条专家评估记录。
19. 专家评估记录应按 `evaluationId + artworkId + expertId` 保证唯一。
20. 专家必须使用系统登录账号访问评估，权限判断以 `expertId` 为准。
21. 管理员不能代替专家填写、保存、提交或修改专家评估记录。
22. 专家之间互不可见，专家不能查看其他专家的评分、评语和最终估价。
23. 审核人不能查看专家草稿态评估内容。
24. 评估项目完成进度应按 `艺术品数量 × 专家数量` 计算。
25. 评估项目必须在全部专家评估记录提交后才能提交审核。
26. 提交审核前，系统必须校验必填指标、最终估价和币种是否完整。
27. 审核通过后，评估项目进入已完成状态，默认不允许继续修改专家评估结果。
28. 审核驳回应支持定位到某个专家对某件艺术品的单条评估。
29. 单条专家评估被驳回后，仅该条评估进入可修改状态，其他专家评估结果不受影响。
30. 被驳回的专家重新提交后，项目可再次提交审核。
31. 每次审核通过或驳回都必须保存审核记录和审核意见。

- `evaluation.project.create`：管理员创建评估项目。
- `evaluation.project.edit`：管理员编辑评估项目。
- `evaluation.project.delete`：管理员删除评估项目。
- `evaluation.project.view`：查看评估项目详情与结果。
- `evaluation.project.submitReview`：提交项目审核。
- `evaluation.metric.manage`：维护指标定义与模板。
- `evaluation.review.self`：专家查看自己的评估记录。
- `evaluation.review.self.edit`：专家保存草稿、提交评估、修改被驳回评估。
- `evaluation.review.result.view`：管理员查看项目评估结果汇总。
- `evaluation.audit.view`：审核人查看待审项目与审核历史。
- `evaluation.audit.approve`：审核人审核通过。
- `evaluation.audit.reject`：审核人驳回单条专家评估。

### 11.1 评估项目管理

```http
GET /api/evaluations
POST /api/evaluations
GET /api/evaluations/{id}
```

接口规则：

- `PUT /api/evaluations/{id}` 在 `DRAFT`、`PENDING` 状态可修改项目全量配置。
- 项目进入 `IN_PROGRESS` 后，`PUT /api/evaluations/{id}` 不得再修改艺术品列表、专家列表和项目指标。
- `DELETE /api/evaluations/{id}` 建议仅对未开始项目开放；已进入执行或已有审核痕迹的项目建议改为逻辑删除或取消。

```http
GET /api/evaluations/{evaluationId}/artworks/{artworkId}/my-review

```

接口说明：

- `my-review`：专家查看或编辑自己的评估记录，不返回其他专家的评估内容。

- `reviews`：管理员查看某件艺术品下所有专家评估结果；审核人仅可查看已提交到审核流的结果，不返回草稿态内容。

### 11.10 评估审核

```http
POST /api/evaluations/{id}/submit-review
GET /api/evaluations/{id}/audit-records
POST /api/evaluations/{id}/audit/approve
POST /api/evaluations/{id}/expert-reviews/{reviewId}/audit/reject
```

接口说明：

- `submit-review`：提交审核，系统校验评估完整性后将项目状态改为 `IN_REVIEW`。
- `audit-records`：查询审核历史。
- `audit/approve`：审核通过，项目状态改为 `COMPLETED`。
- `expert-reviews/{reviewId}/audit/reject`：驳回某条专家评估，项目状态改为 `REVIEW_REJECTED`，请求中必须包含驳回原因。

## 12. 验收标准

### 12.1 创建评估项目

- 管理员可以填写评估项目名称和说明。
- 管理员可以配置一个或多个艺术品筛选条件。
- 管理员可以选择筛选字段、操作符和值。
- 系统可以展示匹配艺术品数量。
- 系统可以展示匹配艺术品预览列表。
- 管理员确认后，系统保存固定艺术品列表。
- 管理员可以选择评估指标模板并导入。
- 管理员可以从评估指标库拖拽指标定义到评估项目。
- 管理员可以调整本项目评估指标。
- 管理员可以为评估项目指定多个专家账号。
- 创建成功后，系统生成评估项目记录。
- 创建成功后，系统能为每个“专家 + 艺术品”组合生成专家评估记录和评估页面。

### 12.2 编辑 / 删除评估项目

- 管理员可以编辑评估项目。
- 管理员可以删除未开始的评估项目。
- 评估项目进入 `IN_PROGRESS` 后，系统不允许修改艺术品、专家、项目指标。
- 评估项目进入 `IN_PROGRESS` 后，如允许继续编辑，仅允许修改不影响评估口径的基础信息。
- 已进入执行或已有审核历史的项目，删除应采用逻辑删除、取消或其他可审计方式。

### 12.3 评估指标定义管理

- 用户可以新增指标定义。
- 用户可以编辑指标名称、编码、分类、说明、评分类型、分值范围、评分说明和分档标准。
- 用户可以停用指标定义。
- 用户可以复制已有指标定义创建新指标。
- 指标定义修改后应形成新版本或更新版本号。
- 历史评估项目不受指标定义后续修改影响。

### 12.4 评估指标模板管理

- 用户可以新增模板。
- 用户可以编辑模板名称和说明。
- 用户可以在模板中新增、编辑、删除指标。
- 用户可以设置模板内指标分值范围、是否必填、排序。
- 用户可以停用模板。
- 停用模板不影响历史评估项目。

### 12.5 指标拖拽配置

- 用户可以在评估项目编辑页看到指标库。
- 用户可以将指标定义拖拽到本项目指标区。
- 拖拽后系统生成项目指标快照。
- 用户可以调整项目指标排序。
- 用户可以编辑项目指标的必填状态、分值范围、输入控件和评分说明。
- 保存后专家评估页面应按最新项目指标生成。
- 评估项目进入 `IN_PROGRESS` 后，项目指标区域应只读。

### 12.6 条件字段配置

- 用户可以选择用于筛选艺术品的字段。
- 不同字段展示合适的操作符。
- 文本字段支持包含、等于、不为空。
- 日期字段支持年份、日期区间。
- 系统能根据条件返回匹配艺术品。
- 创建评估项目后，条件快照可在项目详情中查看。
- 评估项目进入 `IN_PROGRESS` 后，不允许再调整艺术品范围。

### 12.7 专家评估

- 专家必须先登录系统账号。
- 专家可以看到分配给自己的评估项目。
- 专家可以查看艺术品详情。
- 专家进入评估页面时，页面应由项目指标自动生成。
- 专家只能看到自己的评估记录。
- 专家不能看到其他专家对同一艺术品的评分、评语和估价。
- 专家可以按指标打分。
- 专家可以查看指标评分说明和分档标准。
- 专家可以填写最终估价。
- 专家可以保存草稿。
- 专家可以提交评估。
- 管理员不能代替专家填写、保存、提交或修改评估内容。
- 必填指标未完成时不允许提交。
- 被审核驳回的单条评估，只能由对应专家重新修改和提交。

### 12.8 评估审核

- 当评估项目下所有“专家 + 艺术品”评估均已提交后，项目可进入待提交审核状态。
- 管理员或具备提交权限的专家可以将评估项目提交审核。
- 提交审核时，系统应校验必填指标、最终估价和币种是否完整。
- 审核人可以查看待审核评估项目。
- 审核人可以查看每件艺术品下各专家已提交的评分、评语和最终估价。
- 审核人不能查看专家草稿态评估内容。
- 审核人可以填写审核意见。
- 审核人可以审核通过评估项目。
- 审核人可以驳回某个专家对某件艺术品的单条评估，驳回时必须填写原因。
- 审核通过后，评估项目状态变为已完成。
- 审核驳回后，仅被驳回的单条专家评估允许修改并重新提交。
- 系统应保存审核历史记录。

### 12.9 结果查看

- 用户可以查看评估进度。
- 用户可以查看按艺术品和专家聚合的指标评分。
- 用户可以查看各专家评语。
- 用户可以查看各专家最终估价。
- 用户可以查看评估项目创建时使用的条件。
- 用户可以查看本次评估项目使用的指标来源。
- 用户可以查看审核状态、审核意见和审核历史。

## 13. 待确认问题

1. 多专家评估的汇总估价是人工选择，还是系统自动计算平均值、中位数或去极值平均？
2. 评估指标是否需要支持权重参与计算？
3. 最终估价是单一金额，还是区间估价，例如 100,000 - 150,000？
4. 评估结果是否需要导出 Excel？
5. 提交后的评估是否允许修改？
6. 是否需要生成正式评估报告？
7. 创建评估项目时，艺术品是否永远保存为固定列表？
8. 是否需要区分人民币、美元、港币等币种？
9. 评估条件是否需要支持 OR 条件组？
10. 模板是否需要区分艺术品类型，例如书画、油画、瓷器、雕塑？
11. 模板是否需要复制已有模板快速创建新模板？
12. 指标定义是否需要审批流程，还是管理员保存后立即可用？
13. 指标定义版本是否需要保留完整历史，还是仅在项目快照中保留历史？
14. 审核人是否需要独立账号权限，还是先用“审核人名称”文本字段？
15. 审核驳回后，专家是否只能修改被驳回字段，还是可以修改该条评估的全部内容？
16. 审核通过后是否允许管理员重新打开项目？
17. 是否需要支持多级审核，例如初审、复审、终审？

- 创建评估项目时从指标库拖拽指标定义。
- 导入或拖拽后可调整本项目评估指标。
- 评估项目进入 `IN_PROGRESS` 后锁定艺术品、专家、项目指标。
- 支持一个评估项目指定多个专家。
- 系统自动为每个“专家 + 艺术品”组合生成专家评估页面。
- 专家必须使用登录账号。
- 专家之间互不可见。
- 管理员不能代替专家填写或修改评估。
- 支持评估项目提交审核。
